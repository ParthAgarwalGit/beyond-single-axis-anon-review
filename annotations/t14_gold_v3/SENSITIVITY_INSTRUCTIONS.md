# T06 sensitivity set — full-response labelling

A **separate, smaller** pass: 60 items. Do this **after** your primary
file is finished and returned.

The only difference is the `full_response` column: it contains the model's **entire**
reply including its internal reasoning, where the primary set showed the final answer
only. Everything else — the 0–3 scale, the 2/3 rule, `human_validity` — is identical.

Item ids here (`S###`) are unrelated to the primary ids and are in their own random
order. Do not try to match them up with items you have already labelled; judge each one
fresh on what is in front of you.

The purpose is to measure whether seeing the reasoning trace changes the label. That
measurement only works if you judge these independently rather than trying to reproduce
your earlier answer.

44,859 words across 60 items.

Fill `human_validity` and `label_0_to_3` for every row. Do not reorder rows or edit any
other column.
